# Vishwa Sharma — Personal Portfolio & Engineering Showcase 🚀

> **Computer Science & Engineering Student @ Swami Keshvanand Institute of Technology (SKIT), Jaipur**
> Outside Hitter / Spiker @ SKIT Volleyball Team

A high-performance personal portfolio built with Apple Cupertino Minimalist Dark Titanium aesthetics and Google Fluid design principles, featuring an interactive starfield with physics-based cursor repulsion, zero harsh divider lines, and deep algorithmic foundations.

---

## ⚡ Tech Stack & Highlights

- **Aesthetic**: Apple Dark Mode Minimalist Titanium × Google Fluid Cards
- **Interactive Background**: Dynamic Canvas Starfield with distance-based physics repulsion (stars dodge the mouse cursor) and titanium ambient auras
- **Frontend Core**: Semantic HTML5, Tailwind CSS, Lucide Icons, Vanilla JavaScript (zero build step, instant load)
- **Academic Spotlight**: Swami Keshvanand Institute of Technology (SKIT), Jaipur
- **Core Engineering**: C++20, Java 21, Data Structures & Algorithms (Trees, Graphs, DP, Shortest Paths)
- **Athletics**: Competitive Volleyball (Outside Spiker, reaction velocity, court vision)
